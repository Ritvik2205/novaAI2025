#### Agent ↔ Human Handoff Guidelines

- **Trigger Conditions:** Human escalation is required when budget negotiations exceed agent authority, legal clauses need modification, or the partner requests a custom demonstration.
- **Preparation Checklist:**
  - Summarise conversation context in ≤ 8 bullet points.
  - Highlight outstanding questions or risks.
  - Attach latest quote draft, project code, and recommended student groups.
- **During the Call:** Human representative keeps the agent console open so action items, meeting notes, and scheduling updates flow back into the CRM in real time.
- **Post-Call Sync:** Agent generates a transcript summary, updates opportunity status, and sends partner recap email within 15 minutes.
- **Fallback:** If no human responds within defined SLA windows, the agent offers to continue in automation mode or to book the next available slot automatically.
